# 거래량 폭발 전략 (Volume Breakout Strategy) - 초안

## 📋 **전략 개요**
6개월 횡보하는 코인에서 거래량이 폭발할 때 진입하여 단기 수익을 추구하는 전략

## 🎯 **핵심 전략 로직**
1. **6개월 횡보 감지** → **2개월 낮춰서** 전략 실행
2. **거래량 폭발** 감지 (30일 평균의 5배 이상)
3. **양봉** 확인 (일봉 기준)
4. **5% 수익** 시 매도
